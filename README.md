# Minds Research Companion

Lightweight Chrome Web Store MVP for Minds.

## What it does

Highlight text on any webpage, right-click, choose **Send selection to Minds**, then copy the selection and open Minds for research.

## Install locally

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked**.
4. Select this folder.

## Store positioning

**Short description:** Send selected text to Minds for quick audience-reaction research.

**Privacy:** This extension does not collect, store, or transmit browsing history. Selected text is only shown locally in the extension page and copied when the user clicks the button.

The product link is naturally present through the extension’s Open Minds flow and listing page.
